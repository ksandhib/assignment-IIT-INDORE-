# If-Else Assignment - Python for Data Science

## Problem Statement:
You work in XYZ Corporation as a Data Analyst. Your company asked you to work with `if-else` conditions.

### Task:
- Input `a = 10` and `b = 20`.
- Use `if-else` to compare and print:
  - "a is greater than b" if a > b
  - "b is greater than a" if b > a
  - "a and b are equal" if a == b

## Files:
- `main.py` - Python script containing the code.
- `output.txt` - Output after running the code.

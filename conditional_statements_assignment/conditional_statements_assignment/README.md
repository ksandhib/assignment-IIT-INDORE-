# Conditional Statements Assignment - Python for Data Science

## Problem Statement:
As a Data Analyst at XYZ Corporation, you've been asked to use conditional statements to find the greatest of three numbers.

### Task:
- Take three numbers as input from the user.
- Use `if-else` statements to:
  - Identify the greatest number.
  - Handle edge cases where two or more numbers are equal.

## Files:
- `main.py` - Python script with the solution.
- `output.txt` - Example output from sample input.

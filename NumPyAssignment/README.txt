NumPy Assignment - IntelliPaat

This project demonstrates basic usage of NumPy for:
- Matrix creation and reshaping
- Type conversion from int to float
- Array appending
- Element-wise addition
- Slicing rows and elements from a matrix

Files:
- numpy_tasks.py → contains main logic
- helper_numpy.py → optional helper file
- README.txt → this file

Instructions:
Run numpy_tasks.py using a Python interpreter with NumPy installed.
Enter 4 integers separated by space when prompted.
